# Datasets

Datasets and benchmarks for evaluating chained tool-calling agents,
agent reliability, security, planning, memory, and multi-step task execution.

## Included Resources

- WebArena
- AgentDojo
- AgentBench
- WebShop
- Mind2Web
- BrowserGym
- OSWorld
- OSWorld-V
- Other relevant agent-evaluation datasets and benchmarks

## Purpose

This directory collects datasets and benchmark environments that can be
used to study failure modes in autonomous and tool-using agents.
