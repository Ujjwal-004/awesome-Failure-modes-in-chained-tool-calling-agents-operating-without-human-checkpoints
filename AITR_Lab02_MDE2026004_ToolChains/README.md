# AITR Lab 02 — Ujjwal Gupta (MDE2026004)

**Title:** Evaluating Risk-Adaptive Checkpoints for Failure Containment in Chained Tool-Calling Agents.

This is a reproducible **synthetic simulation**, not a live LLM evaluation. It compares no checkpoints, periodic post-action checks (every four actions) and risk-adaptive pre-action checks (before high-risk actions). It measures strict success, unsafe action exposure, recovery and reviewer burden.

## Requirements
Python 3.9+; matplotlib for figures; only Python standard library is used for simulation. No dataset download or external model/API key is required. All scenarios are programmatically generated. Original paper/review are inputs to research framing; no restricted material is redistributed.

## Reproduction commands (executed in the project environment)
```bash
python scripts/test_simulator.py
python scripts/run_experiments.py
python scripts/make_figures.py
```

Compiled manuscript: `paper/main.tex` and `paper/main.pdf`. A PDF build is available with `cd paper && pdflatex main.tex && pdflatex main.tex`; `.bib` is included as a source bibliography for reference metadata, while a self-contained bibliography is embedded in `main.tex` to avoid requiring BibTeX at compilation.

## Experimental protocol
`configs/protocol.json` freezes the five seeds, 400 scenarios per seed-length combination, three lengths, model probabilities, checkpoint schedules and metric definitions. Every policy receives the same exogenous fault and risk streams within each matched scenario. The primary result file has 18,000 individual policy-runs. Sensitivity data contain 18,000 further executions (three risk-recognition recall levels across 6,000 scenarios).

## Integrity and limitations
Every reported numeric result is generated by the supplied scripts. Neither LLM calls nor humans participated in trials; probabilities and scores are synthetic design parameters. The two checkpoint strategies differ in timing (pre-risk vs. periodic post-action), so results are not a pure test of risk recognition alone. The experiment does not reproduce a published benchmark and should not be characterized as a validated system for real-world safety. All external citations were transcribed from user-provided materials and should be individually checked against originals before dissemination.
